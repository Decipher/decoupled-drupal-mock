# Examples

Each is a project that uses the mock as a consumer would, run in CI.

| Example      | Shows                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------ |
| `jest`       | CommonJS in jsdom on Node 16: axios spies, an adapter and a shared server                  |
| `vitest`     | A server per suite, and an extension for a module the preset does not have                 |
| `playwright` | A browser reading across origins, with a reset after each test                             |
| `cypress`    | Tasks for reset and sign-in                                                                |
| `nextjs`     | A real Next.js site with next-drupal, covering draft mode and a save calling the site back |
| `extensions` | The extensions those use                                                                   |
